# FreeDaDonn · Portfolio

Personal portfolio site, "Navigation by the Stars" theme.

## Structure
```
index.html      → page content (edit text here)
css/style.css   → all styling (colors are in :root at the top)
js/main.js      → compass + star-chart animations
mockups/        → early design explorations
```

## Run locally
Open `index.html` in a browser, or in VS Code install the **Live Server** extension → right-click `index.html` → "Open with Live Server".
